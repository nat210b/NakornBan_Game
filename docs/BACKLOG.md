# MVP Backlog

## Epic 1: Lobby & Room
- As a player, I can create a room with a room code.
- As a player, I can join a room using a code.
- As a host, I can start the game once enough players join.
- As a player, I can see the player list and ready state.

## Epic 2: Realtime Sync
- As a player, I see join/leave events in real time.
- As a player, I see phase changes in real time.
- As a player, I see card dealing and trail updates in real time.
- As a player, I see arrests and win/lose results in real time.

## Epic 3: Role & Card Dealing
- As a player, I receive a private role.
- As a player, I receive 4 weapon + 4 evidence cards.
- As Murderer, I select 1 weapon + 1 evidence as truth.
- As Forensic, I can view the correct answer privately.
- As Witness, I can see the Murderer identity privately.

## Epic 4: Forensic Trail
- As Forensic, I can place 6 trail cards in Round 1.
- As all players, I can see the trail layout.
- As Forensic, I can replace 1 trail card per later round.

## Epic 5: Arrest Flow
- As investigators, I can nominate arrests.
- As the game, I can validate arrest correctness.
- As a room, we see win/lose result and game ends.

## Epic 6: Chat & System Log
- As a player, I can send chat messages.
- As a player, I can see system log messages (phase changes, arrests).

## Epic 7: Admin/Host
- As host, I can end/reset a game.
- As host, I can kick a player (optional).
